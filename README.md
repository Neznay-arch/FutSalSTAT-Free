# Futsal Stat - Статистика матчей по мини-футболу

Веб-приложение для ведения статистики матчей по мини-футболу (футзалу). Работает прямо в браузере без установки дополнительных зависимостей.

## Как запустить

1. Откройте файл `index.html` в любом современном браузере:
   - **Двойным кликом** по файлу в проводнике/Finder
   - Или перетащите файл в окно браузера
   - Или через меню браузера: Файл → Открыть файл

2. Приложение готово к работе! Никаких серверов и сборщиков не требуется.

## Что работает на Этапе 1

### Экран "Новый матч"
- ✅ Ввод названия Команды 1
- ✅ Ввод названия Команды 2
- ✅ Выбор длительности периода (по умолчанию 20 минут)
- ✅ Кнопка "Начать матч"

### Экран "Матч"
- ✅ Отображение названий команд
- ✅ Крупное табло со счётом
- ✅ Таймер обратного отсчёта (формат MM:SS)
- ✅ Отображение текущего периода
- ✅ Кнопки "+1 гол" для каждой команды
- ✅ Кнопка "Пауза/Продолжить" для таймера
- ✅ Кнопка "Завершить матч" (возвращает на стартовый экран)

### Логика работы
- ✅ Таймер стартует автоматически при начале матча
- ✅ По истечении времени периода предлагается перейти к следующему
- ✅ Счёт увеличивается по клику на кнопку
- ✅ Все данные сохраняются в localStorage
- ✅ При перезагрузке страницы матч восстанавливается
- ✅ Адаптивный дизайн под мобильные устройства
